Plusieurs missions internes pour le bon fonctionnement de l'entreprise.

## Préparation des postes avec Ninite

Pour éviter d'installer les applications une par une, j'ai utilisé **Ninite**, qui installe automatiquement les logiciels courants. J'ai entièrement configuré les PC des nouveaux employés avec les applications dont ils avaient besoin.

## Nouvelle imprimante

- Configuration à partir de l'**adresse IP** de l'imprimante.
- Attribution à chaque employé d'un **code personnel à 4 chiffres**.
- Installation des pilotes sur tous les postes, environ 10 minutes par PC.

## Installation électrique

Le 4ᵉ étage changeait de fournisseur d'électricité. J'ai vérifié les prises de tous les bureaux pour éviter les coupures pendant les rendez-vous clients.
