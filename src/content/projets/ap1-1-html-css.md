Le premier mois du BTS était consacré aux deux langages de base du web :

- **HTML**, langage de balisage qui structure les pages grâce aux balises qui entourent chaque élément ;
- **CSS**, langage de règles de style qui soigne la présentation, via une feuille de style reliée au HTML.

## Démarche

J'ai appris ces deux langages sur **OpenClassrooms**, une plateforme de cours en ligne. C'est un premier exemple de ma façon d'apprendre : en autonomie, à partir de ressources en ligne.

## Résultat

J'ai codé mon propre **CV en HTML/CSS** : une page pour la structure, une feuille de style pour la mise en forme. Un premier projet concret, avec un objectif précis.
