PHP est un langage libre utilisé pour produire des pages web dynamiques via un serveur HTTP.

## Objectif

Développer un site dynamique pour une école de **cours de musique**, à partir d'une architecture fournie et en respectant un cahier des charges.

## Réalisation

- Pages générées en PHP à partir des données du site.
- Mise en forme avec une feuille de style CSS.
- Vérification du résultat dans le navigateur, page par page.

Les captures montrent le code PHP, le CSS et le rendu final.
